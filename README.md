# Alma Colombia — Piloto Web (Viajes con Propósito 60+)

Prototipo piloto de sitio web para viajes boutique en Colombia diseñados para adultos activos de 60 a 75 años (grupos exclusivos de máximo 12 personas).

- Idiomas: Español, Inglés y Japonés.
- Nota: las fechas, cupos disponibles y testimonios son ilustrativos para el prototipo.
